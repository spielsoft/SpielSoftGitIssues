# SpielSoftGitIssues

A self-contained plugin for serial GitHub issue triage, local implementation,
independent review, and owner-authorized squash merging across SpielSoft projects.

Initial development targets local Codex execution using Git and authenticated
GitHub CLI. ChatGPT host support requires capability verification; Claude Code
adaptation is planned. The plugin is not yet implemented or installable.

SpielOrders is the first commissioning target; SpielPasswords follows.

See [workflow decisions](docs/workflow-decisions.md) and
